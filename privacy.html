Privacy Policy - Faint Signal Tools

Faint Signal Tools is a private application used only by the owner of the Faint Signal YouTube channel to manage that channel.

The app uses the YouTube Data API to upload videos and to read and update the metadata and analytics of the owner's own channel. It does not access any other user's data.

Data is stored only on the owner's private server, is never sold or shared with third parties, and is used only to manage the channel.

You can revoke the app's access at any time at https://myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
